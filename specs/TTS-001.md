## 1. Objetivo

Adicionar **leitura em voz alta em PT-BR** ao Decky Translator para acessibilidade de crianças e pessoas com dificuldade de leitura. O plugin deve funcionar **100% offline** (padrão) e opcionalmente **online** via provedores de nuvem configuráveis pelo usuário (URL + API Key).

Fora de escopo v1.0: novo OCR, streaming TTS, SSML avançado, novo overlay visual.

## 2. Arquitetura

Mantém padrão Decky: **Frontend React (TypeScript, decky-frontend-lib)** <-> **Backend Python (RPC via `serverAPI.callPluginMethod`)**.

### 2.1 Pipeline sob demanda (1 gesto)

```
[L4 segurar] -> main.py
  -> captura PipeWire (Game Mode) / Spectacle (Desktop fallback)
  -> OCR existente (Chrome Screen AI / RapidOCR)
  -> langdetect (fasttext/py3langid)
  -> se EN: tradução (NLLB-200 offline / Google online)
  -> se PT: direto
  -> Normalizer (limpa quebras, ruído OCR)
  -> Chunker (frases <= 400 chars sem cortar palavra)
  -> TTSProvider.synthesize(text) -> WAV temporário
  -> Ducking (wpctl set-volume @DEFAULT_SINK@ 25%)
  -> paplay/pw-play WAV
  -> restore volume (try/finally)
```

- Sem OCR contínuo. Apenas sob demanda para economizar CPU/bateria.
- Debounce: se texto == último texto, ignora.
- Interrupção: segundo L4 -> `speaker.stop()` mata processo paplay.

### 2.3 Contrato OmniVoice (assunção até spec real)

```json
POST {URL_USUARIO}
Headers: Authorization: Bearer {API_KEY}, Content-Type: application/json
Body: {"text": "Olá mundo", "language": "pt-BR", "voice": "faber", "response_format": "wav"}
Response: 200 audio/wav (bytes) | 4xx JSON {"error": "..."}
```

Adapter suporta 2 modos via flag `compat`:
- `openai`: POST `{model, input, voice, response_format}` em `/v1/audio/speech`
- `simple`: POST `{text, language, voice}` em URL base

Mock server local valida antes de apontar para serviço real.

## 4. Critérios de Validação (DoD)

Ver `docs/validation-log.md` e seção 4 do plano aprovado. Resumo:

- Funcionais: painel aparece, offline funciona sem rede, online com URL+Key, Testar voz toca, EN->PT e PT direto, L4 interrompe, chunking, overlay intacto.
- Performance: L4->voz <=3s offline / <=2s online, Piper <=300ms frase curta, CPU <30% 1 core.
- Qualidade: voz inteligível 1.2x, tradução 4/5 correta.
- Acessibilidade: uso só com L4, feedback <200ms.
- Robustez: falha rede com fallback, key vazia bloqueia, volume sempre restaura.
- Compatibilidade: Game Mode LCD/OLED SteamOS 3.5+, sem root.

## 6. Riscos e Mitigações

| Risco | Mitigação |
|---|---|
| OCR fonte estilizada falha 20-30% | ROI + upscale + Chrome Screen AI |
| Latência >3s | Piper rápido + chunk antes de sintetizar |
| OmniVoice spec diferente | Adapter com flag compat + mock |
| Decky API quebra | Fixar decky-frontend-lib version |
| Volume ficar baixo se crash | try/finally no ducking |
